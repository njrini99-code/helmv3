# Database Schema Reference

> **The authoritative section is `AUTOGEN:columns` at the bottom of this file.**
> It is regenerated by `scripts/regen-docs.mjs` from `src/lib/types/database.ts`,
> which `npm run db:types` produces from the live database and CI keeps honest
> (`db:types:check`). It covers **every table and every column** — currently 266
> tables / 3,998 columns.
>
> Everything between here and that block is hand-written narrative kept for its
> explanations of intent and relationships. **Do not trust it for column names.**
> It was last hand-verified 2026-04-21, when it described 80 tables against a
> live schema of 266 — every baseball and admin table was missing. That gap is
> what this file's generated section now closes.
>
> For table purposes and relationships: `memory/glossary.md`.
> Sport prefixes are load-bearing — `golf_*`, `baseball_*`, `lift_*`. An
> unprefixed table name almost certainly does not exist.
