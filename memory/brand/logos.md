- The helm icon is the core brand mark across ALL products
- GolfHelm variant = helm + golf ball center
- BaseballHelm variant = helm + baseball element (TBD)
- Parent brand = helm + ship silhouette
- **Green is the brand color** — the helm must always be green
- Logo should appear in bottom-left or bottom-center of ads
- Minimum size: 36px height for icon mark, 120px wide for full lockup
