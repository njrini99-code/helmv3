# CoachHelm v3

**v3 is the canonical CoachHelm engine.** New generators, composite insights,
counterfactuals, genome, goals, intent, LLM composition, chat, qualifying,
ranking and visibility code belongs here.

v2 (`../v2`) is still on the live path (post-round trigger, orchestrator,
`insights/types` and `insights/upsert`), and 15 files in this folder import its
insight types or upsert helper. Do not add new v2 imports. The retirement plan
and the list of remaining v2 importers are in [`../README.md`](../README.md).
