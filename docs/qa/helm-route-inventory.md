## Route anomalies and test implications

- Golf legacy routes such as `/golf/dashboard/alerts`, `/insights`, and `/patterns` redirect into intelligence; several My-* routes redirect into player CoachHelm/development. Baseball legacy roster/stats/practice/performance paths also redirect to canonical surfaces. Redirect rows above are active aliases, not separate features.
- Routes with no static navigation link should receive a direct-navigation smoke test, especially dynamic player/game/round/event/admin pages.
- Dynamic routes must test wrong-team ids, deleted ids, malformed ids, and not-found behavior. Page-level loading/error files do not prove the data loader handles all Supabase errors.
- Query parameters should be fuzzed only where detected or documented; unknown parameters must not change authorization scope.
- `/admin` and `/golf/admin` use different admin gates and require separate personas.
