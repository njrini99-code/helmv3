# V7 Player Profile Snapshot System

Player profiles should become the organized snapshot of everything the staff knows, not a static recruiting card.

## Profile Header

Show:

- name
- position(s)
- handedness
- class year
- status: active, limited, injured, redshirt, trial, showcase
- today's availability
- latest readiness
- next event
- latest CoachHelm signal
- source trust indicator

## Snapshot Cards

### Performance Snapshot

- official game stats
- scrimmage stats
- practice metrics
- latest trend
- best verified measurables
- stat source freshness

### Hitting Snapshot

- AVG/OBP/SLG/OPS
- chase rate
- zone contact
- hard-hit rate
- exit velocity trend
- game vs practice gap
- latest video
- current hitting focus

### Pitching Snapshot

- ERA/WHIP/K/BB
- first-pitch strike
- command trend
- velocity trend
- pitch shape notes
- workload
- readiness
- latest bullpen
- current pitching focus

### Defense/Catching Snapshot

- position innings
- errors/chances
- throwing metrics
- catcher pop/block/receive metrics
- video tags
- current defensive focus

### Strength Snapshot

- bodyweight trend
- latest lift completion
- key exercise progress
- soreness
- readiness
- workload note
- next lift

### Classes and Availability Snapshot

- class schedule
- conflicts
- eligibility/standing if visible
- travel constraints
- study hall tasks

### Video Snapshot

- latest clips
- assigned clips
- reviewed clips
- public/passport clips
- source/vendor references

### Task and Development Snapshot

- active tasks
- overdue tasks
- development plan items
- meeting notes
- staff owner
- last player meeting

## Timeline

Timeline event types:

- game stat import
- scrimmage result
- practice block completion
- video review
- lift completion
- readiness flag
- class conflict
- coach meeting
- player task completion
- CoachHelm signal created
- CoachHelm action taken
- CoachHelm outcome measured

## Staff Notes

Notes must be scoped:

- public to staff
- private to coach group
- strength-only
- academic-only
- player-visible
- hidden from player

AI can summarize notes only within visibility boundaries.

## Why It Wins

The player profile becomes the single organized player-development operating record. A coach preparing for a player meeting should not open six tools. BaseballHelm should provide the whole story in one place.
