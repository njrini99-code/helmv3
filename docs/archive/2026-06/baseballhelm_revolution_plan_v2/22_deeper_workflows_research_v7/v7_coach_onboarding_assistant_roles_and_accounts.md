# V7 Coach Onboarding, Assistant Roles, and Accounts

Assistant coaches need real accounts. BaseballHelm must not copy the limitation of tools that cap or flatten staff roles. A college baseball staff has real specialization: head coach, pitching coach, hitting coach, catching coach, recruiting coordinator, director of ops, strength coach, academic liaison, scorekeeper, video coordinator, student manager, and admin.

## Account Types

Program accounts:

- owner/admin
- head coach
- assistant coach
- pitching coach
- hitting coach
- catching coach
- infield coach
- outfield coach
- recruiting coordinator
- director of operations
- strength coach
- athletic trainer/readiness viewer
- academic viewer
- video coordinator
- scorekeeper/stat manager
- student manager
- player
- guardian/family
- showcase/scout viewer

## Onboarding Flow

### Program Creation

1. Choose program type: college, JUCO, high school, showcase.
2. Create team/organization.
3. Choose season.
4. Add staff.
5. Choose source systems used.
6. Import roster.
7. Import schedule.
8. Connect or configure stats sources.
9. Configure player access.
10. Configure strength/readiness.
11. Configure practice planning defaults.
12. Review demo checklist.

### Assistant Coach Invite

Fields:

- name
- email
- role
- assigned position groups
- permissions preset
- player note visibility
- stats/edit permission
- practice planning permission
- video review permission
- player messaging permission
- import/upload permission
- AI action approval permission

Invite flow:

- invited coach receives email
- accepts account
- completes profile
- sees role-specific onboarding checklist
- lands in role-specific dashboard

## Permission Presets

Pitching coach:

- pitchers, catchers, pitching stats, pitch events, bullpens, pitcher workloads, pitching practice blocks, video tags, player tasks

Hitting coach:

- hitters, hitting stats, swing/batted-ball data, cage/practice metrics, hitting video, practice blocks, player tasks

Strength coach:

- lifts, readiness, soreness, bodyweight, exercise results, workload context, player availability summary, practice/lift conflicts

Director of ops:

- calendar, travel, documents, announcements, acknowledgements, roster logistics, class conflicts, event attachments

Academic viewer:

- class schedules, eligibility, academic tasks, travel letter conflicts; no private baseball notes unless granted

Scorekeeper/stat manager:

- games, stats imports, official/scrimmage classification, source validation, box score correction workflows

Video coordinator:

- video upload/linking, tags, clip requests, external references, player/staff visibility

## Onboarding Checklists By Role

Head coach:

- invite staff
- import roster
- import schedule
- choose stat sources
- configure roles
- build first practice plan
- review first CoachHelm signals

Assistant coach:

- confirm position group
- review assigned players
- upload/import first development data
- create first practice station
- complete player video review

Strength coach:

- create first lift template
- assign lift group
- configure readiness check-in
- review workload context

Player:

- complete profile
- add class schedule
- complete readiness check-in
- confirm schedule
- watch assigned video

## Why This Matters

GameChanger staff roles give staff broad equal access and have staff-count constraints in public help materials. BaseballHelm should become the serious staff system with many role-specific accounts, granular capability controls, and workflow ownership.
