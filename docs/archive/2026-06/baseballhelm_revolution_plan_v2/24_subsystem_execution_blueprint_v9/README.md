## Controlling Product Rule

Every subsystem must serve at least one of these outcomes:

- help a coach understand what changed
- identify who needs attention
- explain where the data came from
- convert insight into staff or player action
- attach work to calendar/practice/game/lift/video/player timeline
- measure whether the action worked
- protect player/staff permissions
- make the product more useful for college, high school, showcase, or JUCO baseball

If a feature does not satisfy one of those outcomes, it is not part of the Phase 1 build and must be deferred or cut.
