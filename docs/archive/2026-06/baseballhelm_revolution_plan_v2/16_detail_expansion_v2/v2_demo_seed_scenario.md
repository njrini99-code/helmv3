# V2 Demo Seed Scenario

The demo must feel like a real college baseball program, not placeholder data.

## Demo Team

Name: North Shore College Baseball

Roster size:

- 38 players
- 16 pitchers
- 4 catchers
- 10 infielders
- 8 outfielders
- 3 two-way players
- 5 freshmen
- 9 transfers
- 4 limited/return-to-play players

Staff:

- head coach
- pitching coach
- hitting coach
- strength coach
- director of ops
- academic support viewer
- student manager

## Demo Week Story

Set the demo during a Tuesday of conference week.

Recent events:

- weekend series lost 1-2
- offense struggled with runners in scoring position
- bullpen overused on Sunday
- Tuesday lift before practice
- Wednesday practice
- Friday travel
- Friday/Saturday/Sunday conference series

## Seeded Tension

The demo should show real operating pressure:

- closer threw 42 pitches Sunday and is limited today
- starting catcher has a class conflict with early defensive work
- two freshmen have not acknowledged travel itinerary
- three players missed lift completion
- one two-way player is available to hit but not throw
- imported GameChanger/official stat file has one jersey mismatch
- Rapsodo-style bullpen CSV has two low-confidence player matches
- AI daily brief surfaces only source-backed items

## Required Demo Screens

Command Center should show:

- Daily Brief with 4 items
- today practice not yet published
- availability board
- import needing review
- acknowledgement gaps
- top player timeline changes

Player Today should show:

- schedule
- lift/check-in action
- practice group
- travel acknowledgement
- player-safe development note

Player Profile should show:

- timeline with game, practice, lift, wellness, and coach note entries
- player development brief
- source-labeled stats and metrics

Import Center should show:

- one committed roster import
- one stat import with warning
- one pitching metrics import awaiting player match review
- rollback available for the most recent import

Practice Planner should show:

- 90-minute practice plan
- station blocks
- staff owners
- player groups
- AI suggestion tied to weekend stats and availability

Staff Decision Room should show:

- top 5 agenda items
- player trends
- availability issues
- action items

## Demo Data Quality Bar

- No `example` rows in screenshots.
- Names should look like a real roster but not real people.
- Metrics should be plausible for college baseball.
- Dates should align to the same week.
- Every AI insight should have source references.
- Every player-visible card should avoid staff-only details.
