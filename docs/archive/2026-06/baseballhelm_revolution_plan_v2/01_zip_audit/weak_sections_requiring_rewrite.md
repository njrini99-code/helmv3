# Weak Sections Requiring Rewrite

## Future navigation and tabs

The original coach navigation was too large. It should be rewritten as role-based product areas, not 18+ tabs.

## Import center

The original flow was directionally right but underbuilt. It needed matching candidates, validation severities, duplicate resolution, rollback, source labels, and AI mapping review.

## CoachHelm AI

The original AI guardrails were useful, but the product architecture needed to be rewritten away from “chatbot/module list” into embedded briefs, flags, summaries, and action cards.

## Database recommendations

The original table list was useful but insufficient for implementation. It needed indexes, constraints, RLS, examples, feature usage, imports, AI readers, and reports.

## UI/UX

V1 used premium language but needed screen-level intent, primary CTA, empty/error/loading states, mobile behavior, AI placement, and demo mode specifics.

## Phase plan

The original plan asked for too much too soon. V2 defines Phase 0 cleanup, Phase 1 true MVP, Phase 1.5 demo wow layer, and deferred depth.
