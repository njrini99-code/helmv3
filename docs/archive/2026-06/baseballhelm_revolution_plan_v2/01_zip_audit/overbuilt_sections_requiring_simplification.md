# Overbuilt Sections Requiring Simplification

## Recruiting

Recruiting should not be a core Phase 1 feature. BaseballHelm should first win daily operations and player development. Later, an internal roster-needs board can be built; an external recruiting marketplace should not.

## Lifting

Do not build a full TeamBuildr competitor. Build assignments, imported workouts/results, completion, compliance, and performance availability context.

## Academics

Do not build Teamworks Academics. Build class conflict import, practice conflict flags, coach-visible risk summaries, and strict permissions.

## Travel

Do not build a full travel management suite. Build travel itinerary, travel roster, acknowledgements, and calendar linkage.

## AI

Do not build AI everywhere. Build a small set of trusted, source-cited outputs that live in daily workflows.

## Drill library

Do not build a giant drill marketplace early. Build reusable practice blocks and team-specific drill snippets.
