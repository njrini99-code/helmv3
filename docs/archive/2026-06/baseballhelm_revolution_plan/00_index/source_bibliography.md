## Research interpretation note

Sources were used to identify public product claims, market positioning, likely data categories, import/export signals, and workflow coverage. BaseballHelm should not copy proprietary UI or private workflows. It should build original workflows that solve the same customer problems with a baseball-specific, import-first architecture.
