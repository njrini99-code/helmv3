# Academics And Compliance Tools

## Scope

Build lightweight academic visibility, not a full compliance/advising platform.

## Required features

- Player class schedule upload/import.
- Practice/lift/travel conflict warnings.
- Study hall tracker.
- Academic risk tags.
- Advisor notes with restricted visibility.
- Travel conflict list.
- Weekly class conflict report.
- Player self-reported academic tasks.
- AI academic risk summary based only on entered/imported data.

## Privacy

Default academic details should be restricted. Players see their own schedule/tasks. Coaches see risk tags/conflicts based on role. Staff-only notes must never be shown in player AI summaries.
