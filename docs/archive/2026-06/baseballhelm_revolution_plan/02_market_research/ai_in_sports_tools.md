# AI In Sports Tools

## Practical AI opportunity

CoachHelm AI should not pretend to see what data does not exist. It should summarize, rank, explain, and connect the data BaseballHelm actually has.

## Useful AI classes

- Summaries: weekly team health, game recap, player profile summary.
- Alerts: missed lift, availability change, academic conflict, workload spike.
- Pattern detection: player trending up/down, pitch velocity decline, QAB improvement, poor sleep + soreness + missed lift.
- Planning support: practice focus suggestions, player meeting prep.
- Import support: header mapping, row cleanup, duplicate warnings.

## Guardrails

- No medical diagnoses.
- No certainty when data is incomplete.
- Cite source records.
- Keep staff-only data staff-only.
- Player-facing tone must be constructive.
