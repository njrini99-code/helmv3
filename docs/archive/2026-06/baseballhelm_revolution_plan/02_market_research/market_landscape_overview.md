# Market Landscape Overview

College baseball software is fragmented into four overlapping markets:

1. **Athletic department operations:** Teamworks, ARMS, academics/compliance platforms.
2. **Game/stat systems:** GameChanger, NCAA/StatCrew conventions, school website stats providers.
3. **Player development technology:** TrackMan, Rapsodo, Blast, Diamond Kinetics, BaseballCloud, Driveline TRAQ, Hudl/OnForm/CoachNow.
4. **Performance/lifting:** TeamBuildr, BridgeAthletic, TrainHeroic, TrueCoach, CoachMePlus, Smartabase/Kitman/Kinduct-style AMS products.

## BaseballHelm opportunity

No single tool is optimized for a college baseball staff that wants all of this in one practical, affordable, baseball-specific command center. BaseballHelm should not fight each silo directly. It should become the layer where those silos become useful together.

**Recommended positioning:** BaseballHelm is the import-first, AI-assisted operating system for college baseball programs: Teamworks-level organization, baseball-specific development depth, and CoachHelm intelligence without enterprise bloat.
