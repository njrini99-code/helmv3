# Current UI Audit

## Strengths

- Existing layout has a serious SaaS shell with sidebar, cards, badges, and role-based navigation.
- Current UI primitives can support premium refactor if typography, spacing, density, and empty states are standardized.
- Dark/sidebar + glass card language can be retained as a Helm visual signature.

## Problems

- Navigation is not aligned to the future college baseball operating model.
- Player and coach surfaces are still too similar in information architecture.
- Recruiting-era pages create product confusion for the operating-system wedge.
- Academics and travel appear as standalone pages rather than connected cards in command center and player profile.
- Stats/development/video are likely fragmented instead of consolidated around player timeline.

## Future UI direction

- Coaches: dense desktop/tablet command workspace with clear hierarchy, powerful tables, compact filters, and expandable details.
- Players: mobile-first Today screen with cards, check-offs, schedule, task/lift/practice visibility, and constructive summaries.
- AI: quiet insight layer embedded in cards; no sparkle-first gimmick UI.
