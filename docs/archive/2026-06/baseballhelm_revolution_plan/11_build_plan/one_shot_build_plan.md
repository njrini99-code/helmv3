# One-Shot Build Plan

## Phase 1 goal

Ship a working college baseball operating system demo: command center, roster, player profile, calendar, practice, stats, lifting, wellness/availability, imports, and basic CoachHelm AI.

## Step order

1. Branch and freeze current behavior.
2. Add core migrations and RLS.
3. Create typed baseball data services.
4. Refactor nav into module registry.
5. Build roster/player profile identity.
6. Build command center read models.
7. Build calendar/practice/stats/lifts.
8. Build import center.
9. Add AI brief source tables.
10. Seed demo data.
11. QA permissions, import rollback, mobile player UX.
