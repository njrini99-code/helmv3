- **PLAYER session:** Signed out, logged in `rinin376@gmail.com / Pirates#09!!!` successfully → player **Cole Bennett** on **Demo University Golf** (same team as the demo coach; men's; 2 coaches).

- **Blockers / caveats:**
  - Finding #9 could not produce a clean 403: demo documents use a non-existent fake host (`storage.demo.helmsportslabs.com`), not a real Supabase private bucket, and CSP blocked a JS fetch. Both preview and download fail on demo data.

- **No production data was mutated.** All SAFE-FAIL writes (#2 Confirm, #3 Address, #6 Injured) returned `success:false` server-side and reverted; nothing persisted.
