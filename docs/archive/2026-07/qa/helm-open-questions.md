## Assumption discipline

Each provisional assumption must be encoded in test metadata and report output. Security tests should default to the narrower-privilege expectation; product-presence tests should default to “not active” when only a stub, dark component, migration, or provider adapter exists. No unresolved question authorizes production writes or provider calls.
