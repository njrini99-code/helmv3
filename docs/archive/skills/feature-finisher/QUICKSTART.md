# Feature Finisher - Quick Start

## How to Invoke

### Analyze a Specific Feature
```
"Finish the calendar feature"
"Feature finish the messaging system"
"What's missing from CoachHelm?"
"Analyze the round tracking feature for completion"
```

### Analyze Multiple Features
```
"Finish the top 3 highest-impact features"
"What features need the most work?"
"Prioritize feature improvements for next sprint"
```

### Deep Dive
```
"Give me a legendary-level analysis of the calendar"
"What would make stats truly world-class?"
"How could messaging be 10x better?"
```

### Quick Assessment
```
"What layer is the qualifier feature at?"
"Quick assessment of all dashboard features"
"What's the lowest-hanging fruit to improve?"
```

## Pro Tips

1. **Start with high-impact features** - Calendar, Messaging, and Rounds are used daily

2. **Look for quick wins** - Some features are one step away from the next layer

3. **Consider the interconnections** - Finishing one feature might unlock others

4. **Think about the user's day** - What friction do they hit repeatedly?

5. **Don't forget mobile** - Many players check on their phones

## The Mindset Reminder

> You're not finding bugs. You're not doing QA.
> 
> You're being the user who paid $500/year and expects this to be the best golf team management software in the world.
> 
> What would disappoint you? What would delight you? What's missing?
