# Staff Roles And Permissions

## Roles

Head coach, assistant coach, pitching coach, hitting coach, strength coach, director of operations, academic viewer, student manager, admin, player.

## Permissions model

Permissions should be capability-based, not only role-name based. Example capabilities: `view_staff_notes`, `edit_roster`, `publish_practice`, `view_academics`, `manage_lifts`, `manage_imports`, `approve_ai_player_summary`.
