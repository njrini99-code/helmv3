# Coach Account Architecture

The coach account is desktop/tablet-first and built around the Coach Command Center. Every tab should answer either: what happened, what needs attention, what should we do next, or who is responsible.

## Core coach objects

- Team
- Player
- Staff member
- Event
- Practice
- Game
- Lift
- Development session
- Availability status
- Academic conflict
- Travel trip
- Announcement/task
- Import batch
- AI brief/flag
