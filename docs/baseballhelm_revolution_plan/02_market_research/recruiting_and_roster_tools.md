# Recruiting And Roster Tools

## Market pattern

FieldLevel, SportsRecruits, NCSA, Perfect Game, Prep Baseball, ConnectSports, ARMS, and coach spreadsheets all support prospect visibility, evaluation, events, communication, and recruiting boards.

## Recommendation

Recruiting should be Phase 4 or a separate CoachHelm module. The app's immediate wedge should be current-team operations and player development.

## Later module features

- Prospect board.
- Pipeline stages.
- Prospect profile.
- Position need.
- Graduation year.
- School/travel team.
- Contact info.
- Coach owner.
- Evaluation notes.
- Tool grades.
- Video links.
- Event/camp attendance.
- Follow-up tasks.
- Visit dates.
- Offer/commitment status.
- Transfer tag.
- Import prospect list.
- AI recruiting summary.
