# Practice Planning Tools

## Current real-world workflows

College baseball practice is often managed through Google Docs, printed practice plans, spreadsheets, staff text threads, whiteboards, and shared calendars. The plan has time blocks, stations, groups, coach assignments, field/cage/bullpen assignments, and development priorities.

## BaseballHelm native opportunity

Practice planner should become the daily operating tool. It should bridge CoachHelm insights, recent game weaknesses, player development focuses, and attendance/grades.

## Key workflows

1. Review CoachHelm brief.
2. See recent team/player weaknesses.
3. Create practice plan from template.
4. Assign groups and stations.
5. Publish player-facing view.
6. Record attendance and grades.
7. Add coach notes.
8. Generate practice recap.
9. Update player development timelines.

## Build recommendation

Build practice templates, practice blocks, drill library, groups, staff assignments, attendance, grades, recap, and AI practice builder by Phase 1/2.
