# Strength And Conditioning Tools

## Market pattern

TeamBuildr, BridgeAthletic, TrainHeroic, TrueCoach, CoachMePlus, Smartabase/Kinduct-style AMS products focus on programming, workout logging, compliance, readiness, reporting, and athlete monitoring.

## BaseballHelm opportunity

BaseballHelm should build the minimum native lifting module needed to connect strength work to baseball availability and development. It should not replace a major S&C platform at enterprise depth in Phase 1.

## Native Phase 1 features

- Lift calendar.
- Workout assignment to team/group/player.
- Exercise library.
- Sets/reps/load/RPE.
- Completion tracking.
- Missed lift reasons.
- Player maxes and estimated 1RM.
- Readiness, soreness, bodyweight, sleep, hydration.
- Strength coach comments.
- Baseball coach visibility.
- CSV import for assigned/completed lifts.

## Elite later features

- Phase templates.
- In-season/offseason templates.
- Return-to-play modifications.
- Load monitoring dashboards.
- Strength-to-baseball correlation reports.
- AI workload risk indicators.
