# Current BaseballHelm Features

## Current feature surface

Based on current routes and sidebar, the app already has surfaces for:

- Authentication and onboarding.
- Coach/player dashboard.
- Roster.
- Stats.
- Videos.
- Development plan(s).
- Calendar.
- Messages.
- Announcements.
- Tasks.
- Documents.
- Travel.
- Academics for JUCO.
- Program/team settings.
- Recruiting-era discover/watchlist/pipeline/compare/camps/college interest.

## What is promising

- The app already thinks in teams and roles.
- It has communication and task primitives.
- It has calendar/travel/documents surfaces that map well to college operations.
- It has player identity and roster surfaces.
- It has enough app shell and UI base to refactor rather than rewrite everything.

## What is missing

- Unified Coach Command Center.
- Player Today page.
- Practice planner as a first-class baseball workflow.
- Lifting/performance assignment and compliance.
- Wellness/readiness/availability model.
- Hitting and pitching development logs tied to player timeline.
- Arm care and throwing workload.
- Import center with mapping, validation, rollback.
- AI layer grounded in specific in-app data.
- Robust permissions beyond coach/player and coach type.
