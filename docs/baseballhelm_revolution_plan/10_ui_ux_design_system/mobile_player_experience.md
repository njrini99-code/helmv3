# Mobile Player Experience

## Design principle

Premium, clean, fast, college-athletics serious. Dense enough for coaches. Simple enough for players.

## Visual direction

- Dark left navigation.
- Warm cream/stone content surfaces.
- Helm green accent.
- Strong cards and tables.
- Clear hierarchy.
- Minimal but powerful icons.
- AI as integrated evidence cards, not glitter.

## UX requirements

- Every page has loading, empty, error, and permission-denied states.
- Tables have saved filters, search, export where useful, and row-level actions.
- Player profile uses timeline + tabs, not disconnected pages.
- Import flow has dropzone, mapping, preview, validation, commit, history, rollback.
- Mobile player UX prioritizes Today, tasks, lifts, practice, and check-ins.
