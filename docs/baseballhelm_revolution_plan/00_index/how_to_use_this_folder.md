# How To Use This Folder

## For a coding agent

1. Read `00_index/executive_summary.md`.
2. Read `01_repo_audit/current_repo_map.md` and `01_repo_audit/reuse_refactor_replace_matrix.md`.
3. Read `11_build_plan/one_shot_build_plan.md`.
4. Read `08_data_architecture/recommended_tables.md` before writing migrations.
5. Read the tab specs for the feature being implemented.
6. Use the import templates and example CSVs as seed data contracts.
7. Use CoachHelm AI specs only after permissions, audit logs, and source references exist.

## For a product/design agent

Start with `04_future_product_architecture/`, then `10_ui_ux_design_system/`, then coach/player tab specs.

## For a market/research agent

Start with `02_market_research/`, `03_college_baseball_operations_deep_dive/`, and `00_index/source_bibliography.md`.

## For database work

Start with `08_data_architecture/data_model_overview.md`, `recommended_tables.md`, `recommended_columns_by_table.md`, `role_permissions_model.md`, and `rls_policy_recommendations.md`.
