# What Not To Build Yet


## Ruthless phase philosophy

The smallest version that is revolutionary is not the biggest feature list. It is the smallest set of connected loops that make a coach and player come back daily.

## Phase 0 foundation cleanup

- Verify routes/schema/auth.
- Clean nav branches.
- Establish capability checks.
- Add loading/error states for touched routes.
- Confirm reusable components.
