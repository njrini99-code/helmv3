# Coach Command Center V2 Ui


## Premium product principles

- Fast decision-making beats dashboard density.
- Every card needs a source, status, and action.
- Player mobile experience must be simple enough for a 30-second check.
- Coach desktop experience can be denser but must remain scannable.
- AI should feel native: action cards, summaries, inline warnings, not a separate gimmick.
- Empty states should teach and accelerate setup.
- Error states should preserve trust.
- Demo mode should look like a real college program, not fake lorem ipsum.

## Standard screen spec

- Primary user intent
- First thing user sees
- Primary CTA
- Secondary actions
- Data cards
- Tables/filters
- Empty state
- Error state
- Loading state
- Mobile behavior
- Desktop behavior
- AI placement
- Integration points


## Coach Command Center hierarchy

1. CoachHelm Daily Brief
2. Today's schedule and primary event
3. Availability/risk strip
4. Practice plan status
5. Open tasks/acknowledgements
6. Recent imports/changes
7. Player attention list
