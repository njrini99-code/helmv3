# What Changed From Original

## Changed: product center of gravity

V1: broad BaseballHelm platform with many tabs.

V2: daily command system built around coach action, player habit, import trust, and player timeline.

## Changed: navigation

V1: Coach Command Center, Roster, Player Profiles, Calendar, Practice Planner, Lifting & Performance, Game & Stats Center, Hitting Development, Pitching Development, Defense/Baserunning, Availability/Wellness, Academics, Communication, Travel, Recruiting, Reports, Import Center, CoachHelm AI, Settings.

V2: Command, Roster, Calendar/Team Ops, Practice, Stats, Performance, Reports, Import, Admin. AI is embedded. Recruiting is deferred.

## Changed: AI

V1: AI architecture with many modules and prompts.

V2: embedded AI product layer with source refs, confidence, permissions, actions, dismissal, audit, and no unsupported medical/academic claims.

## Changed: data model

V1: table list.

V2: migration-aware `baseball_*` extension plan with identity, import, timeline, AI source refs, acknowledgements, audit logs, and RLS considerations.

## Changed: imports

V1: generic mapper and templates.

V2: import-first product philosophy with row-level preview, matching, duplicate resolution, rollback, audit trail, source labels, and AI-assisted mapping under human approval.

## Changed: phase plan

V1: broad Phase 1.

V2: Phase 0 cleanup, Phase 1 true MVP, Phase 1.5 demo wow layer, then depth after pilot proof.
