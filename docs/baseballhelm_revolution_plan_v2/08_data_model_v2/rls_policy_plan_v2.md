# Rls Policy Plan V2


## RLS policy rules

- Team staff can read team-scoped non-restricted records.
- Players can read their own player-visible records only.
- Staff-only notes never appear in player queries.
- Academic details are restricted to allowed staff roles; coaches see conflicts/availability impact, not sensitive advisor notes by default.
- Wellness/readiness data is staff-restricted and cannot be framed as medical diagnosis.
- Import rows are staff/admin only.
- AI insights inherit the strictest source visibility among source refs.
- Admin settings require org/team owner capability.
