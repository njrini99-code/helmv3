# V5 Player Passport And Recruiting Showcase System

This file upgrades recruiting/showcase from a generic profile feature into a source-backed proof system.

## The Product Name

Player Passport.

## What It Is

Player Passport is a verified baseball identity and development proof packet.

It can power:

- player profile
- coach meeting
- showcase profile
- scout packet
- transfer profile
- high school recruiting exposure
- internal roster evaluation

## Why This Is Different

Recruiting platforms have profiles.

BaseballHelm should have proof.

Proof means:

- source-labeled stats
- verified measurables
- event history
- coach-reviewed metrics
- video/doc links
- development timeline
- visibility controls

## Passport Sections

Identity:

- name
- preferred name
- grad year/class year
- positions
- bats/throws
- height/weight
- team/program
- player status

Verified Measurables:

- 60-yard
- 10-yard split
- exit velocity
- throwing velocity
- pitcher velocity
- spin rate
- pop time
- vertical/broad jump
- strength tests if visible

Each measurable:

- value
- unit
- source
- verified/unverified
- event/date
- visibility

Baseball Performance:

- official stats
- game logs
- season summaries
- development metrics
- coach-reviewed highlights

Development Story:

- timeline
- goals
- coach-shared notes
- practice progress
- strength/performance progress

Media:

- video links
- documents
- reports
- attachments

Exposure:

- public/private state
- profile completeness
- scout packet status
- college interest if enabled

## Program Variants

College:

- internal player passport
- player meeting
- roster evaluation
- transfer/exit packet later

High school:

- recruiting/exposure passport
- coach-controlled public fields
- guardian policies optional

Showcase:

- event passport
- verified measurables
- scout packet export
- college coach viewer access

JUCO:

- transfer-focused passport
- college ops plus exposure

## Scout Packet

Scout Packet outputs:

- event roster
- player cards
- verified metrics
- video links
- contact rules
- source labels
- notes if visible

Export forms:

- web packet
- PDF later
- CSV summary

## Profile Completeness Engine

Completeness categories:

- identity
- positions
- measurables
- stats
- video
- contact rules
- academic/grad info
- source review

Signals:

- missing video
- unverified metric
- missing grad year
- profile not public
- stat import missing

## Visibility Controls

Visibility levels:

- staff only
- player visible
- public profile
- scout packet
- guardian visible
- restricted

Every passport field needs visibility.

## Why This Competes

FieldLevel and SportsRecruits are networks.

Perfect Game and PBR are scouting databases.

BaseballHelm should become the proof layer controlled by the program, powered by source-backed operational history.
