## 2026-10-23 — A dual-role player reads their own round (RR-1)

```text
Design package: none (Clubhouse A+ handoff, W7 RR-1)
PR/commit: #2356

Actions: none
Data impact: none

```

### Changed

- The round review decides who is looking from the resolved dashboard role
  (`resolveClubhouseTeam`), as Roster does, not from "has no coach row". A
  user with a coach row and a player row, acting as the player, sees their
  own round instead of "This round isn’t here". A player on no team still
  reads their own rounds.

### Why

- The route chose the viewer by `session.player && !session.coach`.

### Verification

- New `round-review-role.test.tsx`: both roles of a dual-role user, a player
  on no team and a coach on no team. The player case gave no viewer before.

## 2026-10-23 — CoachHelm is never fetched ahead of the tap (CH-R1)

```text
Design package: none (Clubhouse A+ handoff, W7 CH-R1)
PR/commit: #2356
Contract IDs: none
Actions: none
Data impact: insight exposures are no longer recorded by prefetches
Held items: none
```

### Changed

- New `lib/prefetch-guard.ts`. Every full prefetch (the phone tabs, the
  recent sections, a press, the welcome screen's destination) skips
  `/golf/dashboard/coachhelm`, whose loaders record each insight they return
  as shown. It loads when it is opened. The quiet refresh (A17) skips it for
  the same reason (`recordsOnRead`).

### Why

- The shell fetched CoachHelm whole for every coach and player, so insights
  nobody opened were counted as seen, skewing shown-reads and the track
  record.

### Verification

- New `prefetch-coachhelm.test.tsx`: CoachHelm is a phone tab for both
  roles, yet no prefetch path asks for it; every other tab still is.
