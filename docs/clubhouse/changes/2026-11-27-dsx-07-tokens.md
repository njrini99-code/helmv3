### Changed

- `styles/tokens.css`: four named elevations, `--ch-elevation-flat` (new),
  `-card`, `-raised` and `-overlay`. Seven motion roles,
  `--ch-motion-press-in/-out`, `-popup-in/-out`, `-sheet-in/-out` and
  `-page`, with Reduce Motion variants (the travelling roles become the
  quick fade). Six ring tokens, `--ch-ring-accent*`, `--ch-ring-warn-inset`
  and `--ch-ring-attention-inset`.
- Live stylesheets read the named elevations in place of 29 alias names
  (256 reads) and the vocabulary beats and curves in place of the retiring
  `--ch-ease`, `--ch-ease-sheet` and `--ch-*-spring-*` names (336 reads,
  motion gate 552 to 206). Each swap resolves to the same value, so nothing
  renders differently.
- The reading sheet's `--ch-sheet-shadow` stays: it is a hook, not an alias.
  The shared Section sets it to none on a desk so its one sheet goes flat
  inside it, and the 12 sheet surfaces that had been moved to read
  `--ch-elevation-card` directly drew their shadow inside the Section's card
  (a card in a card, for example the player's Tournaments "Played" table).
  They read the hook again; its value is now `--ch-elevation-card` (it was
  the reading alias, the same shadow). `elevation-roles.test.ts` no longer
  counts the hook as retiring and pins it.
- 31 repeated ring shadows read the new ring tokens (raw shadows 1,148 to
  1,118).
- Under forced colours (Windows High Contrast), 258 surfaces that read a
  named elevation now draw a `CanvasText` outline, since the system drops
  their shadow.
- `npm run clubhouse:css` counts two more things per file that may only
  fall: `raw-type` (a `font` or `font-size` with no type token, 203) and
  `raw-space` (a padding, margin, gap or inset with a raw length, 6,975).

### Why

Nick's 27 Nov design-system programme: the system lived in prose and
ratchets, and page CSS re-drew it by hand. Named roles let a rule say what
it is, and the ratchets stop new stray values while call sites move.

### Left alone

Files held by open PRs #2610, #2655, #2656 and #2658, and modules that are
not live (design lab not-live list), keep their old names; the elevation
and motion ratchets record them.
