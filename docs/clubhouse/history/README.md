`docs/clubhouse/` and from `docs/clubhouse/motion/`, with `git mv`. They are
kept because `PROGRESS.md`, `CHANGELOG.md` and the page docs cite them for what

[QUEUE.md](../QUEUE.md) and [PROGRESS.md](../PROGRESS.md); every audit and plan,

## What stayed in `docs/clubhouse/`

`ALL_PAGE_AUDIT.md`, `SMOOTHNESS_AUDIT.md`, `PREMIUM_AUDIT.md` and
`POPUP_AUDIT.md` are still the "current evidence" that the page docs link to
by hand, so they stay put. `SWAP_AUDIT.md` stays because `STATUS.md` cites its
section 3 as the route alias table. `motion/TEMPLATE.md` and the open
2026-11-07 shell motion report also stay: new motion reports are still written
to `docs/clubhouse/motion/<date>-<scenario>.md` (see the
`helm-safari-performance` skill).

Relative links inside these files were rewritten for their new depth. A path
written in prose (for example `docs/clubhouse/PREMIUM_PASS_AUDIT.md` in a page
CHANGELOG) was left as the text of its day.
