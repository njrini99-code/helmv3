# GolfHelm Stats — Duplicate-Calc (TS layer) + DB-Cache Layer Audit — 2026-06-06

TS duplicate-calc audit: 10 stats, 188 computation sites mapped.

KEY ARCHITECTURE FINDING: two parallel stat layers — (A) TypeScript calculators → player pages; (B) DB functions → golf_round_stats_cache → golf_player_stats_cache → CoachHelm v3 (METRIC_SOURCE registry). They diverge. Root cause of most FW/GIR divergence = the per-round WRITE path (golf.ts saveRound + DB recompute_golf_round_totals + arccos-mapper) using wrong denominators, propagated into the cache.
