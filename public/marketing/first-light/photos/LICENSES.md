# First Light photography — licenses & attribution

Four free-license photographs sourced for the "First Light" landing page
(`docs/LANDING_ENTRY_WORLD_DESIGN.md`, M1 hero + M4 diptych + M8 final CTA).
All are unmodified in *content* (no people/logos/watermarks removed —
there were none) and cropped to portrait framing + resized/re-compressed
for web delivery (max 2400px long edge, JPEG q~55-82, target <500KB).
Cropping + compression is the only editing performed. Color grading to
the pine/ecru palette happens at build time in the app (CSS/canvas), not
baked into these source files.
