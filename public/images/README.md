# Background Images

## Required Auth Background Images

For the auth pages (Layout E design), add the following images:

### Baseball
- **auth-bg-baseball.jpg** - Baseball stadium at dusk/night with lights
  - Resolution: 1920x1080 minimum
  - Style: Slightly dark/moody
  - Format: JPG optimized for web (< 500KB)

### Golf
- **auth-bg-golf.jpg** - Golf course at golden hour
  - Resolution: 1920x1080 minimum
  - Style: Warm, aspirational
  - Format: JPG optimized for web (< 500KB)

## Image Assets
Until high-quality images are added, the auth pages will use gradient overlays with decorative elements.
