## Summary

A single Helm Mission Control sweep (2026-07-30 ~02:35 UTC) filed four distinct, unrelated production defects found in Sentry, explicitly as read-only triage with no fix attempted at filing time:

1. **#1130 — Stripe webhook 500s, escalating, 29 events, still firing at filing time.** `POST /api/webhooks/stripe` throwing in production since 2026-07-29T10:02Z. Because Stripe retries failed webhooks but treats them as delivered, the filing's own framing is stark: "billing events are not being durably recorded even though Stripe considers them delivered-with-failure," against six live invoices totaling ~$6,450.
2. **#1131 — Inngest round-submit fallback, 3 events, 1 real coach affected (Guilford).** `INNGEST_EVENT_KEY` missing/wrong/environment-mismatched in production, causing `submitGolfRoundComprehensive` to fail its Inngest enqueue and fall back to a direct `postRoundTrigger` call. Explicitly framed as "degrades rather than breaks" since the fallback catches the failure — but it means the durable/retryable path was silently unavailable for however long the misconfiguration persisted.
3. **#1132 — RLS refuses INSERT on `golf_conversations`, 1 event, 1 real user, 2026-07-26.** A legitimate first-party `createConversation` call rejected by RLS policy — flagged as worth attention despite low volume because "a single occurrence here most likely means the path is rarely exercised, not that it rarely fails," and explicitly named as the same defect class as the cross-tenant RLS work in #1102/#1105.
4. **#1133 — AI Gateway rejects the model on the free tier, 1 event, 2026-07-26.** Class-schedule photo import fails because the requested AI model isn't available on the current Vercel AI Gateway plan — a billing/plan configuration gap, not a code defect, that "will fail identically for every user on every attempt until the gateway plan or model choice changes."
