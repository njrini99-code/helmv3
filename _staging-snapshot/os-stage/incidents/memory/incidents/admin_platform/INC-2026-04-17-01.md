## Summary

`crmSendEmailApi.send` produced 140 critical-severity rows on 2026-04-17 and
never fired again. The route (`src/app/api/admin/crm/send-email/route.ts`)
still exists and is live in the current tree, so this was not resolved by
deletion — either a transient upstream failure (provider outage, bad batch of
recipient data, a since-fixed bug in a single deploy that shipped and got
patched same-day) or a one-time bad batch send that was manually corrected
and never repeated. **The specific trigger was not identified in this

("Single-day burst, confirmed dead by team-lead context") and did not pull

## Why this is flagged rather than silently dropped

140 *critical*-severity failures in a single day, on an outbound-email path
(CRM coach outreach), is a real user-facing failure mode worth having a named
record of — even resolved, "critical severity, unexplained, single burst,
never recurred" is exactly the kind of gap a future recurrence should be
checked against before anyone re-diagnoses it from scratch. If
`crmSendEmailApi.send` fires again, the first move should be "is this the
same shape as 2026-04-17" before opening a fresh investigation.
