## Summary

`golf_coach_insights` has **608 rows and not one** with `player_id IS
NULL` — the sentinel for a team-scoped (rather than per-player) insight.
Team-level CoachHelm insights have never existed in production, in code
that has been present since 2026-02-05. This was not a "no data yet"
situation: `golf_insight_generation_log` shows the `team_insight` job ran
**21 times between 2026-03-12 and 2026-07-10**, generating 1,343 insights
total — zero of them team-level — against a population that qualified:
Demo University Golf's roster at diagnosis time had 76 active patterns at
confidence ≥0.6, 23 distinct signatures, 17 of those shared by ≥2 players
(the exact bar `generateTeamPatternInsights` requires), and 266 of the 308
qualifying patterns platform-wide predate the last run.

## Root cause (as diagnosed — not independently re-verified here)

The writer itself was checked and found correct: `generateTeamInsights`
builds a proper team record (`insight_type: 'team_trend'`, `player_id:
null`, `team_id: teamId`, `metadata: { cross_player: true, sample_n:
players.length, ... }`). Every downstream gate that could plausibly reject
it was checked and none does:

- Schema — `player_id` is nullable.
- `toInsightInput` — handles team scope explicitly (`stableSignature` uses
  `team_${record.team_id}`); its only rejection condition is `sample_n <
  5`, and the reference team (7 active players) clears that.
- `upsertInsight` — handles a null `player_id` explicitly
  (`.is('player_id', null)`), and the caller passes `coach_id`/`team_id`
  so ownership resolution takes the correct non-null branch.

**The failure is therefore inside the cross-learner** — the component
between pattern qualification and the writer being called — and is
silent: no error, no skipped-reason log, nothing distinguishing "ran and
found nothing to write" from "never actually reached the write call." The
exact break point inside the cross-learner was not identified in the
sources reviewed for this backfill; the issue's own "What is needed"
section frames this as the next diagnostic step rather than a completed
one.

## User impact

Coaches never received any team-level, cross-player CoachHelm insight —
an entire category of intelligence the product was built to provide,
absent for the whole life of the feature. Per-player insights were
unaffected; this is scoped entirely to the team-trend/cross-player
insight type.
