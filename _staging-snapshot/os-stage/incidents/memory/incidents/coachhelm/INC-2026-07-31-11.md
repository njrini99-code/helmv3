## Summary

The causal engine, across 5,641 stored relationships, only ever related a
**scoring component to the overall score** — 4 distinct causes, and
exactly **one** effect (score) across the entire table. A causal-relations
system that can only ever conclude "X affects your score" for every X is
not making a causal claim distinguishable from the trivial fact that golf
scoring components sum to a score — it is a tautology dressed as an
insight. This is the concrete, measurable mechanism behind the standing
product complaint that CoachHelm's insights don't feel root-cause: they
structurally could not, because the effect side of every relationship the
engine was capable of writing was fixed to a single node.

## Root cause (as fixed)

The engine's relationship-writing logic (`orchestrator.ts:534/731`, on the
per-round analysis path) enumerated candidate *causes* from scoring
components but never varied the *effect* side — every relationship it
could produce necessarily terminated at "score." The fix (`80472667a`)
expanded which effect nodes the engine can relate causes to, which is what
makes the resulting relationships informative rather than tautological
(e.g., a cause relating to a specific downstream skill outcome, not only
the aggregate score). The exact set of new effect nodes and the specific
mechanism preventing the old restriction were not itemized in the sources
reviewed for this backfill beyond the commit's own title and the issue's
"Fix" section header — worth reading the PR diff directly if this engine
is touched again.

## User impact

Every causal-relationship-derived insight or explanation shown to a coach,
for the entire life of this engine up to the fix, could only ever express
"this scoring component relates to your score" — a claim with effectively
zero information content beyond what any coach already knows about how
scoring works. Coaches asking CoachHelm "why" were structurally unable to
get an answer more specific than a tautology from this particular engine
output, independent of any other CoachHelm surface's quality.

## Invariant candidate

Yes — two, addressing the two distinct defects found together:

```sql
-- INV-COACHHELM-005a: the causal engine should relate causes to more than
-- one distinct effect type across a rolling window (catches a regression
-- back to the tautology shape).
select count(distinct effect_type) as distinct_effects
from golf_causal_relationships
where created_at > now() - interval '30 days'
having count(distinct effect_type) <= 1;

-- INV-COACHHELM-005b: the causal engine should write new relationships
-- within a bounded window if rounds are actively being analyzed (catches
-- the staleness half independently of the tautology half).
select max(created_at) as last_relationship
from golf_causal_relationships
having max(created_at) < now() - interval '14 days';
```

Severity: MEDIUM-HIGH for both — 005a directly targets the AI-quality
defect this incident is about; 005b generalizes the "green cron, stale
output" shape already established as recurring in this feature area.
