Shared behaviour

Four small files apply the same navigation, states, motion and haptics to every screen.

Navigationgh-nav.js

One list per role drives the desktop sidebar and the mobile tab bar. Only designed screens are listed.

Coach sidebarHome, CoachHelm, Calendar, Team Hub, Messages. Team: Roster, Stats, Qualifiers
Player sidebarHome, CoachHelm, Team Hub. My game: Rounds. School: Classes
Coach tabsHome, CoachHelm, Calendar, Stats, More
Player tabsHome, CoachHelm, Rounds, Team Hub, More

Loading and emptygh-states.jsx

Skeletons copy each screen’s real grid, so nothing moves when content arrives.

SkeletonShow only if data takes longer than 150ms, then keep it at least 300ms. Crossfade to content in 260ms.
SpinnersNever for page loads. Only inside a button while its action runs, like Sync.
RevisitsShow cached data and refresh quietly. No skeleton.
Empty stateAn icon, a title that names what belongs here, one or two sentences on how it fills, one main action.

Motiongh-polish.css · gh-core.js

Short, quiet and consistent. Nothing bounces except the release of a press.

Press110ms ease-out, shrinks about 6px. Springs back over 280ms.
Quick180ms for hover, toggles and tab underlines.
Base260ms for sheets, panels and state crossfades.
Page reveal520ms, 10px rise, 55ms stagger, at most 10 blocks.
Shimmer1.9s linear, one sweep shared by every block.
CurvesEase-out (.22,1,.36,1). Spring (.34,1.3,.64,1). In-out (.65,0,.35,1).
Reduced motionNo rise, press or shimmer.

Hapticsgh-core.js

Most taps are silent. Haptics mark a choice, a commit or a warning.

SelectionTabs, segmented controls, switches, par picker, RSVP choice, checkboxes
Light impactPrimary buttons like Next, Continue and New round
Medium impactA sheet settling at a stop, a shot logged during tracking
SuccessPost, Save, Import, Publish, Send, Share, Assign, Start round, Got it
WarningRemove, Delete, Discard, Exit round, Dismiss
ErrorAn import or sync fails
PlatformsiOS web has no haptics, so press feedback carries it. Native builds use the iOS feedback generators. Android web uses the vibration patterns in gh-core.js.
