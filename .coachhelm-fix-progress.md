## Known Risks

1. **Calibration cold-start:** If `golf_confidence_calibration` is empty, `bootstrapFromDb()` returns empty record, bucket lookups fail, fallback to raw confidence. Mitigation: already coded.

2. **Async/await chaining:** All 5 callers now await. If one fails to catch errors, insight ranking silently skips that player. Mitigation: each caller already error-catches independently; `rankEvidenceInsights` catches calibration load errors.

3. **Behavior multiplier range:** Conservative [0.8, 1.5] to avoid over-correction. Monitor first week post-deploy; adjust if needed.
