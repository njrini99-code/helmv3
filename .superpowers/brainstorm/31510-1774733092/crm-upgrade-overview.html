CRM Premium Upgrade — 3 Pillars

Comprehensive upgrade for real outreach starting this week

1

Visual Polish & Cohesion

Current: Basic emojis (🎯💬🤝🏁), inconsistent card styles, no glass effects, generic feel

Upgrade: Premium Lucide icons throughout (drop all emoji), glass-premium cards matching the golf dashboard, refined typography, consistent dark sidebar + cream content area, smooth transitions between tabs, status colors that feel intentional

Scope: All 6 tabs get the same design treatment — no tab feels like a different app

2

Email System Upgrade

Current: Basic textarea composer, no preview, merge tags shown as code blocks, no scheduling, no follow-up automation

Upgrade:

  • Rich email composer with live preview pane (see what the coach sees)
  • Template system with visual previews, not just names
  • Merge tag insertion via toolbar buttons (not manual typing)
  • Gmail mode: pre-compose with subject + body, one-click open
  • Helm mode: branded email with Helm Sports Labs header/footer
  • Send scheduling — "Send Monday 9am EST"
  • Email performance dashboard — opens, clicks, bounces per campaign
3

Workflow & Feature Cohesion

Current: Tabs feel disconnected, no guided flow, "Research Next 10" misleading, status changes don't always sync

Upgrade:

  • Dashboard becomes a real "command center" — today's tasks, stale leads, recent activity
  • Coach detail panel becomes the single source of truth — timeline of all touches, email history, scheduled events
  • Pipeline Kanban gets drag-and-drop with auto-follow-up prompts
  • Conference view gets batch outreach — select a conference, email all coaches in it
  • Inbound leads get notification badges + one-click add-to-pipeline
  • Status transitions auto-set follow-up dates and suggest next actions

Recommended Approach: Ship in Priority Order

Since outreach starts this week, I recommend: Pillar 2 (Email) first → Pillar 1 (Visual) → Pillar 3 (Workflow). The email system is the tool you'll use most in the first week. Visual polish makes it feel professional when you're in it all day. Workflow refinements compound over time as you build pipeline.
